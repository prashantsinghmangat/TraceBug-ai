Microphone Not granted

Only used if you turn the microphone on for a recording, to narrate what you are doing. Nothing is recorded until you start a recording, and the audio stays in the report on your device.

It has to be granted here rather than from the toolbar popup: a popup closes the moment Chrome's permission prompt takes focus, which cancels the request before you can answer it. This page stays open, so the prompt works.

Record current tab (no picker) Not granted

Lets the popup's "Tab" record mode capture the current tab directly, with no browser share-picker. Chrome shows this as "Read and change all your data on all websites" when you grant it — the same wording as the all-sites permission below, since both let a script read tab content. Not available in Firefox; "Tab" falls back to the share picker there.

Access to all sites Granted

Granted in an earlier version. It no longer does much on its own — a capture always ends when you leave the site it started on, with or without this — so there is nothing to lose by removing it.

Sites allowed to run AI analysis

The first time a site asks TraceBug to analyze a report, you approve it and TraceBug remembers. After that each site is limited to 10 analyses a minute, so a page cannot quietly spend your API credits. Remove a site here to be asked again.

Redaction rules

App-specific PII masked at capture, on top of TraceBug's built-in token/secret patterns.

Comma or newline separated. Matches form fields, storage keys, URL params, and JSON keys in captured data — "email" also covers "customer_email".

One regex per line, case-insensitive. Masked in console output, network response bodies, error text and the DOM replay — not in URLs, screenshots or video.

Having trouble?

Copies TraceBug's version, your browser and OS, which permissions you've granted, and TraceBug's own recent errors. No URLs, no page content, nothing you've captured.

Upgrading from before 1.11? Earlier versions stored these tokens in each website's own storage, where scripts on that site could read them. Revoke and re-create any token you configured before 1.11, then enter the new one here.
